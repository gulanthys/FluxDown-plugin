# Bilibili视频下载插件

`fluxdown@bilibili-bangumi` 是一个面向 FluxDown 的 Bilibili 番剧解析插件。它会从 Bilibili 番剧页面读取分集列表，再为每一集解析 DASH 视频和音频地址，交给 FluxDown 下载引擎处理。

## 功能

- 支持 Bilibili 番剧播放页：`/bangumi/play/ss...` 和 `/bangumi/play/ep...`
- 支持 Bilibili 番剧媒体页：`/bangumi/media/md...`
- 支持移动端 Bilibili 番剧链接
- 自动发现正片分集，并按集生成下载任务
- 可选发现番外、预告、PV、采访等分区
- 支持 DASH 视频画质选择：最佳、2160p、1440p、1080p、720p、480p
- 支持仅下载音频（M4A）
- 每个可用画质会生成独立下载条目，名称保持视频原名并追加画质（例如 [1080p-高清]）
- 优先使用高质量音频轨道，并将视频与音频交给 FluxDown 合并下载流程
- 支持浏览器 Cookie 头和 Netscape `cookies.txt` 格式
- 支持 FD 插件认证入口：Bilibili 二维码登录和登录态复用
- 支持以 `bilibili-bangumi` provider 订阅番剧，在新分集出现后自动创建下载任务
- 显式输入的 Cookie 会规范化并缓存，后续解析可以复用已保存登录态
- 生成安全的文件名和番外分区目录名

## 系统要求

- FluxDown `0.1.44` 或更高版本
- 能够访问 `api.bilibili.com`
- 需要登录权限的内容必须提供有效的 Bilibili Cookie
- DASH 音视频合并需要在 FluxDown 组件设置中安装或配置 FFmpeg

## 安装

### 从 `.fxplug` 安装包安装

当前 Flutter 客户端的“通过 ZIP 安装”文件选择器只显示 `.zip` 文件。发布包同时提供 `.zip` 和 `.fxplug`，直接选择 `.zip` 安装即可：

1. 打开 FluxDown 的“设置 → 扩展 → 插件”。
2. 点击“通过 ZIP 安装”，选择 `bilibili-bangumi-0.1.14.zip`。
3. 安装成功后，在已安装插件列表中确认并启用插件。

不要先解压再通过 ZIP 安装。插件包根目录必须直接包含：

```text
manifest.json
resolve.js
```

### 开发目录安装

开发时可以直接选择本目录 `bilibili-bangumi`，使用 FluxDown 的开发目录安装功能。目录中必须直接存在 `manifest.json` 和 `resolve.js`。

## 配置

安装插件后，在插件卡片的设置中可以配置：

| 设置 | 说明 | 默认值 |
| --- | --- | --- |
| 导入 Bilibili Cookie | 支持浏览器 Cookie 请求头或 Netscape `cookies.txt` 内容 | 空 |
| 复用已保存登录态 | 没有显式 Cookie 时复用插件缓存的登录态 | 开启 |
| 包含番外与花絮 | 同时列出番外、预告、PV、采访等分区 | 关闭 |
| 优先最高画质 | 每集只展示最高可用画质，避免长番剧超过清单上限 | 关闭 |
| 默认画质 | 无人值守或选择超时时使用的画质 | 最佳画质 |

Cookie 只应从自己的浏览器登录态导出，不要提交到 Git 仓库或分享给他人。Cookie 失效后，重新导入即可。

## 登录

在插件卡片中点击“认证/登录”：

1. 插件申请二维码并交给 FD 客户端展示；
2. 使用 Bilibili App 扫描并确认；
3. 插件在同一登录会话中自动轮询，成功后由 FD 保存 `SESSDATA` 等认证 Cookie；
4. 后续解析自动复用已保存登录态，认证未过期前不需要重复扫码。

登录成功后可在同一位置点击“注销”；注销会清除该插件保存的认证档案。

## 使用

1. 在浏览器或其他位置复制 Bilibili 番剧播放页/媒体页链接。
2. 将链接交给 FluxDown 创建下载任务。
3. 插件先返回番剧分集清单。
4. 选择需要的分集和画质；若未手动选择，则使用插件中的默认画质。
5. FluxDown 为每一集获取短期播放地址并开始下载。

每一集会以番剧名和集数命名；番外等分区会放入对应的子目录。

## 解析流程

插件分两阶段工作：

1. 番剧链接 → 调用 Bilibili 番剧接口，读取正片及可选附加分区的分集。
2. 单集标识 → 调用播放接口获取 DASH 视频/音频短期直链，再返回给 FluxDown。

插件本身不负责后台订阅轮询，也不主动创建任务；订阅轮询、去重、过滤和建任务由 FluxDown 核心负责。

## 番剧订阅

在 FluxDown 的 RSS/订阅向导中，将来源选择为 `Bilibili 番剧 · bilibili-bangumi`，地址填写番剧播放页、媒体页或单集页，例如：

```text
https://www.bilibili.com/bangumi/play/ss12345
```

订阅每轮读取番剧分集列表，并按直接下载接口返回的全部可用画质生成独立条目；标题会显示实际画质，例如 `[720p 高清]`、`[1080p 高码率]` 或 `[2160p HDR 真彩]`。核心启动订阅任务时会把指定画质交回插件二段解析，因此 4K、HDR、高码率会沿用直接下载的音视频合并逻辑。订阅使用插件中的 Cookie 和“包含番外与花絮”设置；“默认画质”只影响普通链接解析，订阅会返回全部可用画质。`仅音频` 不适用于订阅条目。播放地址是短期直链，因此暂停很久后再启动任务可能需要重新刷新订阅或手动重试。

可在订阅的筛选设置中按标题过滤画质，例如：

包含：1080p|720p
排除：HDR

其中 | 表示“或”。如果希望同一集保留多个画质，不要开启“智能剧集去重”，否则核心会把同一集的不同画质视为重复剧集。
## 常见问题

### 安装窗口看不到 `.fxplug`

将文件扩展名改为 `.zip` 后再选择。不要把文件内容改成普通文本，也不要重复压缩。

### 安装后解析失败

依次检查：

- FluxDown 版本是否至少为 `0.1.64`；
- 插件是否已启用；
- Bilibili 链接是否为番剧播放页或媒体页；
- Bilibili Cookie 是否有效，是否有对应内容的访问权限；
- 客户端是否能够访问 `api.bilibili.com`。

### 只能看到部分画质

Bilibili 返回的画质取决于账号权限、视频本身和当前播放接口结果。插件只会展示接口实际返回的画质，默认画质不会提升账号本身没有的权限。

### 下载地址很快失效

播放地址是短期直链。插件将其标记为临时地址，建议在解析完成后尽快开始下载；如果任务长时间暂停后失败，可以重新解析或重试任务。

## 文件

- `manifest.json`：插件身份、匹配规则、设置项和入口声明。
- `resolve.js`：Bilibili 番剧分集发现、Cookie 处理、DASH/FLV 地址解析和画质选择逻辑。
- `auth.js`：二维码登录会话、轮询和认证档案保存。
